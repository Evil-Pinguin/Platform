# Безопасное дополнение к текущему проекту

Для ветки `arena/01a0e77b-platform` (сцена `TestLevel.unity` в состоянии после отката слияния). **Не выполняйте `git pull` чужой ветки** ради этих изменений: старый генератор сцены перезаписывает изменения вашего проекта.

Пакет содержит новые спрайты, четыре скрипта, шаблон только новых объектов сцены и `Concepts/apply_platforming.py`. Существующие персонажи, GachaSystem, цветы и пропуск `Ground_Far` не меняются. Скрипт укорачивает только стартовую землю, поднимает два декора на новый уступ и добавляет новые объекты по свободным fileID. Повторный запуск ничего не меняет.

## Применить (Unity закрыта)

В PowerShell из папки **вашего** `Platform`:

```powershell
Expand-Archive -LiteralPath "$HOME\Downloads\PlatformingPatch.zip" -DestinationPath . -Force
py -3 Concepts\apply_platforming.py
```

Если `py` отсутствует, попробуйте `python Concepts\apply_platforming.py`. До любых изменений утилита проверяет версию сцены, коллизии fileID и наличие ассетов. Перед записью она создаёт в корне проекта файл `TestLevel.unity.before-platforming.bak` и никогда не перезаписывает его.

После применения: откройте Unity и `Assets/Scenes/TestLevel.unity`, проверьте уровень. Новые элементы: высокий уступ и дальний провал, подвижная и обрушающаяся платформы, корни, ложная стенка с кристаллом. Секрет — у правого края низины (около x=8); стенка раскрывается от касания, кристалл собирается только после этого.

## Если нужно отменить ТОЛЬКО изменение сцены

Закройте Unity и восстановите исходную сцену из резервной копии:

```powershell
Copy-Item .\TestLevel.unity.before-platforming.bak .\Assets\Scenes\TestLevel.unity -Force
```

Добавленные скрипты и картинки останутся в проекте как неиспользуемые файлы; существующие файлы проекта эта команда не трогает. Не используйте `git reset --hard` или `git clean` — они могут удалить ваши локальные изменения.
